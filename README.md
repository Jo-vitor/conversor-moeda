<h1 align="center"> Challenge ONE - conversor de moedas </h1>

## Resumo do projeto
Projeto para converter moedas, visando a prática com a linguagem Java e os conceitos do paradigma de orientação a objetos.
Feito para o challenge da Oracle Next Education.

## 🔨 Funcionalidades do projeto

- `Converter dólar para real`
- `Converter real para dólar`
- `Converter euro para real`
- `Converter real para euro`
- `Converter peso argentino para real`
- `Converter real para peso argentino`

## ✔️ Técnicas e tecnologias utilizadas

- ``Java``
- ``InteliJ IDEA``
- ``Paradigma de orientação a objetos``
- ``Consumo de api``
